# HobbyFind PRD

## 1. 제품 상세 설명

### 서비스 개요
HobbyFind는 운동형, 지능형, 예술형의 세 가지 카테고리로 분류된 취미를 탐색할 수 있는 웹서비스다. 로그인 없이 모든 주요 기능을 이용할 수 있다.

### 핵심 목표
- 전체 취미를 이미지 카드로 한눈에 보여준다.
- 카테고리별 페이지에서 관심 분야의 취미를 모아 보여준다.
- 모바일과 데스크톱에서 읽기 쉽고 편리한 화면을 제공한다.

## 2. 참고 서비스 및 근거

Airbnb의 이미지 중심 카드와 그리드 구성을 참고한다.
일관된 이미지 크기, 명확한 글자, 충분한 여백을 활용해 사용자가 여러 취미를 쉽게 살펴볼 수 있도록 한다.

## 3. 핵심 기능 및 사양

### 메인 페이지
- 상단바에 로고와 운동형·지능형·예술형 카테고리 메뉴를 배치한다.
- Hero 영역에 서비스 소개 문구를 표시한다.
- 전체 취미 18개를 카드 그리드로 표시한다.
- 각 카드에 이미지, 취미 이름, 짧은 설명, 카테고리를 표시한다.
- 카테고리 메뉴를 클릭하면 해당 카테고리 전용 페이지로 이동한다.

### 카테고리별 페이지
- 운동형, 지능형, 예술형 페이지 총 3개를 구성한다.
- 페이지 상단에 선택된 카테고리 이름과 소개 문구를 표시한다.
- 해당 카테고리에 속한 취미 6개만 카드 그리드로 표시한다.
- 현재 선택된 카테고리 메뉴를 시각적으로 구분한다.
- 로고를 클릭하면 메인 페이지로 이동한다.

### 고정 취미 목록
- 운동형: 조깅/러닝, 요가, 수영, 자전거, 클라이밍, 댄스
- 지능형: 독서, 퍼즐, 체스, 프로그래밍, 외국어 학습, 사진 촬영
- 예술형: 그림 그리기, 악기 연주, 요리, 서예, 도자기 만들기, 정원 가꾸기

## 4. 사용자 페르소나 및 시나리오

### 사용자 페르소나
새로운 취미를 찾고 싶은 직장인 또는 학생이다.
회원가입 없이 다양한 활동을 살펴보고, 관심 있는 분야의 취미를 비교하고 싶어 한다.

### 이용 시나리오
1. 사용자가 메인 페이지에 접속한다.
2. 서비스 소개와 전체 취미 카드를 살펴본다.
3.Concat 관심 있는 카테고리 메뉴를 클릭한다.
4. 해당 카테고리 페이지에서 취미 6개를 확인한다.
5. 다른 카테고리 메뉴를 눌러 관심 분야를 바꾸거나 로고를 눌러 메인 페이지로 돌아간다.

## 5. 기술 스택

| 구분 | 기술 | 용도 |
| --- | --- | --- |
| 프레임워크 | Next.js App Router | 페이지 구성 및 라우팅 |
| UI | React | 재사용 가능한 컴포넌트 구현 |
| 언어 | TypeScript | 취미 데이터와 컴포넌트 타입 정의 |
| 스타일 | Tailwind CSS | 색상, 간격, 반응형 화면 구현 |
| 애니메이션 | Framer Motion | Hero 등장 효과 |
| 데이터 | 프로젝트 내부 고정 데이터 | 취미 18개 관리 |
| 버전 관리 | Git, GitHub | 변경 이력 저장 및 과제 제출 |

## 6. 제한사항

- 메인 페이지와 카테고리별 페이지 3개만 구현한다.
- 취미 목록은 지정된 18개로 고정하며 변경하거나 확장하지 않는다.
- 로그인, 회원가입, 데이터베이스, 외부 API는 사용하지 않는다.
- 검색, 즐겨찾기, 상세 페이지 등 추가 기능은 구현하지 않는다.
- 개인 맞춤 추천 기능은 제공하지 않는다.
- 취미 카드는 정보 표시 용도로 사용하며 별도의 상세 화면으로 이동하지 않는다.

## 7. 완료 확인 기준

- 메인 페이지에 취미 18개가 표시된다.
- 각 카테고리 페이지에는 해당 취미 6개만 표시된다.
- 로고와 카테고리 메뉴의 페이지 이동이 정상 작동한다.
- 현재 페이지에 맞는 카테고리 메뉴가 강조된다.
- 각 페이지에 주소로 직접 접속하거나 새로고침해도 정상 표시된다.
- 모바일과 데스크톱에서 가로 넘침이나 요소 겹침이 없다.
- 카드 이미지가 정상 표시된다.
- Hero 등장 애니메이션이 자연스럽게 작동한다.
- 기본 이용 과정에서 브라우저 콘솔 오류가 발생하지 않는다.
