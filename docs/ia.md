# HobbyFind IA

## 1. 전체 사이트맵

HobbyFind
├── 메인 페이지 (/)
└── 카테고리
    ├── 운동형 (/category/sports)
    ├── 지능형 (/category/intellectual)
    └── 예술형 (/category/arts)

## 2. 사용자 흐름

1. 사용자가 메인 페이지에 접속한다.
2. 서비스 소개와 전체 취미 18개를 확인한다.
3. 상단 카테고리 메뉴를 선택한다.
4. 선택한 카테고리 페이지로 이동한다.
5. 해당 카테고리의 취미 6개를 확인한다.
6. 다른 카테고리 메뉴를 선택하거나 로고를 눌러 메인으로 돌아간다.

로그인이나 회원가입은 필요하지 않다.

## 3. 내비게이션 구조

모든 페이지에서 동일한 상단바를 사용한다.

| 항목 | 이동 위치 |
| --- | --- |
| HobbyFind 로고 | / |
| 운동형 | /category/sports |
| 지능형 | /category/intellectual |
| 예술형 | /category/arts |

현재 페이지에 해당하는 카테고리 메뉴를 강조한다.
메인 페이지에서는 특정 카테고리를 강조하지 않는다.
브라우저의 뒤로 가기와 앞으로 가기를 지원한다.

## 4. 페이지 계층 구조

- 최상위: 메인 페이지
- 하위: 카테고리 페이지 3개
- 취미 상세 페이지는 구성하지 않는다.
- 각 카테고리 페이지는 주소로 직접 접속할 수 있다.

## 5. 페이지별 콘텐츠 구성

### 메인 페이지
1. 상단바
   - HobbyFind 로고
   - 운동형, 지능형, 예술형 메뉴
2. Hero 영역
   - 서비스 제목
   - 서비스 소개 문구
3. 취미 목록
   - 전체 취미 18개
   - 이미지, 이름, 짧은 설명, 카테고리를 포함한 카드
   - 반응형 그리드 배치

### 운동형 페이지
- 카테고리 이름과 소개 문구
- 조깅/러닝, 요가, 수영, 자전거, 클라이밍, 댄스 카드

### 지능형 페이지
- 카테고리 이름과 소개 문구
- 독서, 퍼즐, 체스, 프로그래밍, 외국어 학습, 사진 촬영 카드

### 예술형 페이지
- 카테고리 이름과 소개 문구
- 그림 그리기, 악기 연주, 요리, 서예, 도자기 만들기, 정원 가꾸기 카드

## 6. 상호작용 패턴

- 로고와 카테고리 메뉴는 클릭 및 키보드로 이용할 수 있다.
- 메뉴에 hover, focus, 현재 선택 상태를 표시한다.
- 취미 카드는 정보 표시용이며 클릭해도 다른 페이지로 이동하지 않는다.
- 클릭 기능이 없는 카드에는 버튼이나 링크 역할을 부여하지 않는다.
- 메인 페이지 Hero에 자연스러운 등장 애니메이션을 적용한다.
- 동작 줄이기 설정을 사용하는 경우 애니메이션을 최소화한다.
- 존재하지 않는 카테고리 주소는 404 안내 화면을 표시한다.

## 8. 컴포넌트 계층 구조

RootLayout
├── Header
│   ├── Logo
│   └── CategoryNav
└── 페이지 콘텐츠
    ├── 메인 페이지
    │   ├── HeroSection
    │   └── HobbyGrid
    │       └── HobbyCard × 18
    └── 카테고리 페이지
        ├── CategoryIntro
        └── HobbyGrid
            └── HobbyCard × 6

취미 데이터는 공통 데이터 파일에서 관리한다.
Header, HobbyGrid, HobbyCard는 재사용한다.

## 9. 상단바 및 하단바

### 상단바
- 모든 페이지에 표시한다.
- 로고와 카테고리 메뉴 3개를 포함한다.
- 모바일에서도 모든 메뉴에 접근할 수 있도록 배치한다.

### 하단바
- 이번 프로젝트에서는 별도 하단바를 구성하지 않는다.
