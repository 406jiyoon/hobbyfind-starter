# HobbyFind 유스케이스

## 1. 개요

HobbyFind는 로그인 없이 전체 취미와 카테고리별 취미를 탐색하는 웹서비스다.

사용자는 방문자이며, 회원과 비회원을 구분하지 않는다.
취미 목록은 운동형, 지능형, 예술형 각 6개씩 총 18개로 고정한다.

## 2. UC-01: 전체 취미 탐색

### 목적
전체 취미를 한눈에 살펴본다.

### 시작 조건
사용자가 메인 페이지(/)에 접속한다.

### 기본 흐름
1. 상단바에 로고와 카테고리 메뉴가 표시된다.
2. Hero 영역에 서비스 소개가 표시된다.
3. 취미 18개가 카드 그리드로 표시된다.
4. 사용자가 스크롤하며 이미지, 이름, 설명, 카테고리를 확인한다.

### 완료 조건
사용자가 전체 취미 목록을 확인할 수 있다.

### 예외 처리
- 이미지 로딩에 실패하면 대체 이미지를 표시한다.
- 카드 내용은 이미지가 없어도 읽을 수 있도록 유지한다.

## 3. UC-02: 카테고리별 취미 탐색

### 목적
관심 있는 카테고리의 취미만 살펴본다.

### 시작 조건
사용자가 사이트의 어느 페이지에든 접속해 있다.

### 기본 흐름
1. 사용자가 상단바에서 카테고리 메뉴를 선택한다.
2. 선택한 카테고리의 전용 페이지로 이동한다.
3. 카테고리 이름과 소개 문구가 표시된다.
4. 해당 카테고리의 취미 6개가 표시된다.
5. 선택된 카테고리 메뉴가 강조된다.

### 페이지별 취미
- 운동형: 조깅/러닝, 요가, 수영, 자전거, 클라이밍, 댄스
- 지능형: 독서, 퍼즐, 체스, 프로그래밍, 외국어 학습, 사진 촬영
- 예술형: 그림 그리기, 악기 연주, 요리, 서예, 도자기 만들기, 정원 가꾸기

### 완료 조건
주소, 페이지 제목, 강조된 메뉴, 표시된 취미의 카테고리가 일치한다.

### 대체 흐름
사용자가 다른 카테고리 메뉴를 선택하면 해당 페이지로 이동한다.

## 4. UC-03: 메인 페이지로 돌아가기

### 목적
카테고리 탐색 후 전체 취미 목록으로 돌아간다.

### 시작 조건
사용자가 카테고리 페이지에 접속해 있다.

### 기본 흐름
1. 사용자가 상단바의 HobbyFind 로고를 선택한다.
2. 메인 페이지(/)로 이동한다.
3. 서비스 소개와 전체 취미 18개가 표시된다.
4. 특정 카테고리 메뉴의 강조가 해제된다.

### 완료 조건
사용자가 전체 취미를 다시 탐색할 수 있다.

## 5. UC-04: 주소로 직접 접속 및 새로고침

### 목적
메뉴를 거치지 않아도 원하는 페이지를 이용한다.

### 기본 흐름
1. 사용자가 유효한 페이지 주소를 브라우저에 입력한다.
2. 해당 페이지의 콘텐츠가 표시된다.
3. 새로고침해도 동일한 페이지가 정상 표시된다.

### 유효한 주소
- /
- /category/sports
- /category/intellectual
- /category/arts

### 예외 처리
존재하지 않는 주소에 접속하면 404 안내와 메인으로 이동하는 링크를 표시한다.

## 6. 공통 UI 및 UX 기준

- 모바일과 데스크톱에서 콘텐츠가 겹치거나 가로로 넘치지 않는다.
- 로고와 카테고리 메뉴는 마우스와 키보드로 이용할 수 있다.
- 메뉴에 hover, focus, 현재 선택 상태를 표시한다.
- 취미 카드는 정보 표시용으로 사용하며 상세 페이지로 이동하지 않는다.
- 로딩이 발생하는 경우 진행 중임을 알 수 있도록 표시한다.
- 예기치 않은 오류가 발생하면 오류 안내와 재시도 수단을 제공한다.
- 목록이 비어 있는 경우 안내 문구를 표시한다.
- Hero 등장 애니메이션은 과하지 않게 적용한다.
- 동작 줄이기 설정을 사용하는 경우 애니메이션을 최소화한다.

## 7. 범위 제외

로그인, 회원가입, 검색, 정렬, 즐겨찾기, 취미 상세 페이지,
개인 맞춤 추천, 데이터베이스 및 외부 API 연동은 구현하지 않는다.
