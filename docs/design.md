# HobbyFind 디자인 가이드

## 1. 디자인 시스템 개요

### 디자인 방향
Airbnb의 이미지 중심 카드와 여백 활용 방식을 참고한다.
밝고 편안한 분위기로 취미를 쉽게 탐색하도록 구성한다.

### 핵심 원칙
- 사진과 취미 이름이 먼저 눈에 들어오도록 한다.
- 카드 크기와 간격을 일관되게 유지한다.
- 로고와 메뉴의 이동 기능을 명확히 표시한다.
- 모바일에서도 읽기 쉬운 글자와 충분한 터치 영역을 제공한다.
- 로그인, 검색, 즐겨찾기, 상세 페이지 등은 추가하지 않는다.

## 2. Tailwind CSS 색상 팔레트

| 용도 | 색상 이름 | HEX |
| --- | --- | --- |
| 브랜드 | brand | #BE185D |
| 브랜드 hover | brand-hover | #9D174D |
| 브랜드 연한 배경 | brand-soft | #FDF2F8 |
| 기본 배경 | background | #FFFFFF |
| 보조 배경 | surface | #F9FAFB |
| 기본 텍스트 | foreground | #111827 |
| 보조 텍스트 | muted | #4B5563 |
| 경계선 | border | #E5E7EB |
| 포커스 표시 | focus | #BE185D |

### 적용 예시
- 로고: text-brand
- 일반 본문: text-foreground
- 보조 설명: text-muted
- 선택된 메뉴: bg-brand-soft text-brand
- 경계선: border-border
- 포커스: focus-visible:ring-2 focus-visible:ring-brand

기존 Tailwind 설정과 전역 CSS 구조를 확인한 후 색상을 확장한다.
기존 UI 컴포넌트에서 사용하는 색상 변수와 충돌하지 않도록 한다.

## 3. 타이포그래피

- 기본 글꼴: 시스템 sans-serif
- 본문 기본 크기: 16px
- 본문 줄 간격: 1.6
- Hero 제목: 모바일 32px, 데스크톱 48px
- 카테고리 제목: 모바일 28px, 데스크톱 36px
- 카드 제목: 18px, 굵게
- 카드 설명: 14px, 보조 텍스트 색상

제목과 설명 사이에 충분한 간격을 둔다.
한글 단어가 불필요하게 잘리지 않도록 word-break: keep-all을 적용한다.

## 4. 페이지 구현 가이드

### 메인 페이지
상단바 → Hero → 전체 취미 카드 그리드 순서로 구성한다.

Hero 문구:
- 제목: 나에게 맞는 취미를 찾아보세요
- 설명: 운동형, 지능형, 예술형 취미를 둘러보고 새로운 즐거움을 발견하세요.

Hero 아래에는 전체 취미 18개를 표시한다.
전체 취미는 운동형, 지능형, 예술형 순서로 배치한다.

### 카테고리 페이지
공통 상단바 → 카테고리 소개 → 취미 카드 그리드 순서로 구성한다.

카테고리 소개:
- 운동형: 몸을 움직이며 활력을 채우는 취미를 만나보세요.
- 지능형: 배우고 생각하며 새로운 자극을 주는 취미를 만나보세요.
- 예술형: 만들고 표현하며 일상에 감성을 더하는 취미를 만나보세요.

각 페이지에는 해당 취미 6개만 표시한다.

## 5. 레이아웃 컴포넌트

### 공통 콘텐츠 영역
- 최대 너비: 1200px
- 화면 가운데 정렬
- 좌우 여백: 모바일 16px, 태블릿 24px, 데스크톱 32px
- 섹션 간 간격: 모바일 32px, 데스크톱 48px

예시:
max-w-[1200px] mx-auto px-4 md:px-6 lg:px-8

### Header
- 흰색 배경과 아래쪽 얇은 경계선
- 로고와 카테고리 메뉴 3개 배치
- 모바일: 로고와 메뉴를 두 줄로 배치 가능
- 데스크톱: 로고와 메뉴를 한 줄로 배치
- 메뉴 클릭 영역 높이 최소 44px
- 현재 카테고리는 연한 브랜드 배경과 브랜드 글자색으로 강조
- 현재 메뉴에는 aria-current="page" 적용

### HeroSection
- 제목과 설명을 명확히 구분
- 위아래 충분한 여백
- 제목은 굵게, 설명은 보조 텍스트 색상
- 불필요한 버튼이나 검색창은 추가하지 않음

### HobbyGrid
- 모바일 1열
- sm 이상 2열
- lg 이상 3열
- xl 이상 4열
- 카드 간 간격 24px

예시:
grid grid-cols-1 gap-6 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4

### HobbyCard
- 이미지 → 카테고리 → 취미 이름 → 설명 순서
- 이미지 비율 4:3
- 이미지에 object-cover 적용
- 이미지 모서리 반경 16px
- 카드 이름과 설명의 배치를 일관되게 유지
- 카드 전체를 링크나 버튼으로 만들지 않음
- 클릭 기능이 없으므로 pointer 커서를 사용하지 않음

### Footer
별도 하단바는 구성하지 않는다.

## 6. 이미지 가이드

- 취미별 이미지는 public/thumbnails 폴더에서 관리한다.
- 실제 파일명과 취미 데이터의 이미지 경로를 일치시킨다.
- 취미 내용을 알아볼 수 있는 이미지를 사용한다.
- 이미지에 의미 있는 대체 텍스트를 제공한다.
- 이미지 크기를 지정해 로딩 중 레이아웃이 흔들리지 않도록 한다.
- 이미지 로딩 실패 시 프로젝트 내부의 대체 이미지를 표시한다.

## 7. 상호작용 패턴

### 메뉴
- hover: 연한 브랜드 배경 표시
- active: 눌림 상태를 시각적으로 표시
- focus-visible: 명확한 포커스 테두리 표시
- 상태 전환 시간: 약 150ms

### 카드
- 정보 표시용으로 유지한다.
- hover 시 이미지 확대나 카드 이동은 적용하지 않는다.
- 모바일에서는 hover 없이 모든 정보를 확인할 수 있도록 한다.

### Hero 애니메이션
Framer Motion으로 메인 페이지 Hero에 등장 효과를 적용한다.
- opacity: 0에서 1
- y: 12에서 0
- duration: 약 0.4초
- 한 번만 자연스럽게 실행
- 동작 줄이기 설정에서는 이동 효과를 생략

### 페이지 이동
Next.js Link를 사용한다.
과도한 전환 효과 없이 선택한 페이지를 표시한다.

## 8. 반응형 브레이크포인트

| 구간 | 기준 너비 | 카드 열 수 |
| --- | --- | --- |
| 기본 | 640px 미만 | 1열 |
| sm | 640px 이상 | 2열 |
| md | 768px 이상 | 2열 |
| lg | 1024px 이상 | 3열 |
| xl | 1280px 이상 | 4열 |
| 2xl | 1536px 이상 | 최대 너비 안에서 4열 |

모바일에서 메뉴나 본문이 화면 너비를 넘지 않도록 한다.
사용자가 화면을 확대해도 콘텐츠와 메뉴를 사용할 수 있도록 한다.

## 9. 기본 UX 상태

- 로딩: 실제 대기가 발생하는 경우 간단한 로딩 안내 또는 스켈레톤 표시
- 오류: 오류 안내와 재시도 버튼 표시
- 빈 목록: 표시할 취미가 없다는 안내 문구 표시
- 잘못된 주소: 404 안내와 메인으로 돌아가는 링크 표시

## 10. 디자인 검수 기준

- 모든 페이지의 상단바와 콘텐츠 정렬이 일치한다.
- 카드 이미지 비율과 카드 간 간격이 일정하다.
- 글자와 배경의 대비가 충분하다.
- 현재 선택된 카테고리가 명확히 보인다.
- 키보드 포커스를 확인할 수 있다.
- 모바일에서 가로 스크롤이나 요소 겹침이 없다.
- 애니메이션이 짧고 자연스럽다.
